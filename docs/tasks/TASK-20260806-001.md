# コードコメント記述ルールを CLAUDE.md に追加

## 実行内容

`claude/CLAUDE.md` に「コードコメント記述ルール」セクションを新規追加した。

- コメントは 1〜2 行程度で簡潔に記載する
- 変更の経緯・修正の理由・レビュー向けの説明は書かない（コミットメッセージや PR に書く）
- コードだけでは読み取れない制約・意図のみをコメントにする

`~/.claude/CLAUDE.md` へも同内容を同期済み。
